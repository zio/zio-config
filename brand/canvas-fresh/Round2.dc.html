Five ways to say configuration

Each concept is built on something ZIO Config does: read values from several sources, merge them, fall back to defaults, take overrides, keep settings as keys and values. Same neutral ink and one orange-red, so the shapes carry the idea.

1 Merge

Says configuration: three sources, such as a file, the environment and the command line, join into one resulting value.

Risk: abstract, and can read as a git branch merge or a network diagram.

2 Override

Says configuration: a hollow ring marks the default, a solid knob marks the value that overrides it.

Risk: looks like a plain slider or progress bar, and the ring is faint at 16 px.

3 Slider Z

Says configuration: two settings sliders whose knobs sit at opposite ends, joined into a Z.

Risk: the knobs crowd the bars at 16 px, so it may read as a plain Z.

4 Gear Z

Says configuration: the gear is the universal settings sign, with a Z cut out of it for ZIO.

Risk: the most obvious of the five and a cliché; the Z hole is small at 16 px.

5 Config file

Says configuration: a page of key = value rows: a dot for the key, a bar for the value.

Risk: looks like a generic document icon, and has no Z.

Not covered by any of these yet: validation (a typed value being accepted or rejected). I can fold a check or a typed-value cue into the one you pick.
