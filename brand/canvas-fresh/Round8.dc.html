ZIO Config brand sheet, draft 1

Four switches, one Z

The ZIO Config mark is a stack of four settings switches. The two coloured ones step across so the stack reads as a Z. It says configuration (switches you set) and ZIO (the Z) with no gear and no letter. This is a design draft for Milad to review, not an adopted brand.

1 Mark

The mark, light and dark

Four pill-shaped bars, 14 units tall with a 2 unit gap, in a 64 unit box. Top and bottom bars are ink; the two middle bars are the accent and step from right to left. Each bar has a round knob that is a real hole, so the mark works on any background. The small cut (16 to 23 px) has bars 14.5 units tall.

Rule that follows: the accent on white is 3.53:1. That is fine for the mark (a graphic needs 3:1) but too low for text, and white text on the accent fails too. Use ink on the accent (5.16:1) and never set body text in the accent on white.

3 Type

Sora for the name, outlines in the files

ZIO Config
Configuration for ZIO applications

The wordmark is Sora, ZIO in bold (700) and Config in regular (400), converted to outlines in every logo file so no font is needed. Docs and slides can use Sora for headings and JetBrains Mono for code and small labels.

4 Lockups

Horizontal and stacked

Clear space is one bar height (14 of 64 units, about a fifth of the mark) on every side, shown by the dashed box.

Minimum size: the mark alone down to 16 px (use the small cut below 24 px); the horizontal lockup down to 24 px high. The stacked lockup is for square spaces; use the horizontal one in a header.

5 Icons

Favicon and app icons

Dark tile so it works on light and dark browser chrome. 16 px is a hand-built pixel-grid version without knobs (2 px bars, 1 px gaps); 32 px and up keep the knobs. Files: favicon.svg, favicon.ico (16, 32, 48), apple-touch-icon.png (180), icon-192.png, icon-512.png, and icon-maskable-512.png, which keeps the mark inside the central 80% safe circle for Android adaptive icons.

6 Social

Link preview and GitHub card

Open Graph and Twitter cards are 1200 by 630; the GitHub social preview is 1280 by 640 (dark, same layout). Text is outlined. The tagline "Configuration for ZIO applications" and the zio.dev/zio-config address are placeholders until Milad confirms the wording.

7 Usage

Do not

Don't recolour the bars. Only the ink and accent pairs above.
Don't rotate, skew or flip the mark. The stair only reads as a Z one way.
ZIO Config
Don't set text in the accent on white. It is 3.53:1.
Don't add shadows, gradients or outlines.
