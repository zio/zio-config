ZIO Config brand sheet, final

The Z is a stair of switches

In the ZIO Config logo the Z of ZIO is drawn as four horizontal switches that step across, each with a round knob. It says configuration (switches you set) and ZIO (the Z) without a gear. The Z on its own is the symbol for favicons and app icons, so there is one shape everywhere. Tagline and web address are placeholders until Milad confirms them.

1 Logo

ZIO Config, light and dark

The wordmark is Sora: IO in bold (700) and Config in regular (400), with the stair as the Z, all converted to outlines. The Z is the symbol at cap height: four pill bars, ink on the top and bottom, accent in the middle, each with a round knob that is a real hole. The bars are as thick as the I stem (6.77 against 6.74 units at a cap height of 30), so the Z carries the same weight as the letters beside it.

1b Symbol

The symbol: the Z on its own

The same stair used alone where there is no room for the name: favicon, app icons, avatars. Four pills of 14 units with a 2 unit gap in a 64 unit box. It is identical to the Z in the logo, so the symbol and the wordmark never differ. The small cut (16 to 23 px) has bars 14.5 units tall.

Rule that follows: the accent on white is 3.53:1. That is fine for the mark (a graphic needs 3:1) but too low for text, and white text on the accent fails too. Use ink on the accent (5.16:1) and never set body text in the accent on white.

3 Type

Sora for the name, outlines in the files

Configuration for ZIO applications

The wordmark is Sora: IO in bold (700) and Config in regular (400), with the stair as the Z, converted to outlines in every logo file so no font is needed. Docs and slides can use Sora for headings and JetBrains Mono for code and small labels.

4 Clear space and size

Room around the logo

Clear space is one bar height (about a quarter of the cap height) on every side, shown by the dashed box.

Minimum size: logo 32 px high, so the knobs stay visible. Below that use the symbol (small cut from 16 px).

5 Icons

Favicon and app icons

Dark tile so it works on light and dark browser chrome. 16 px is a hand-built pixel-grid version (3 px bars, 1 px gaps, a 1 px dot for each knob); 32 px and up use the full knobs. Files: favicon.svg, favicon.ico (16, 32, 48), apple-touch-icon.png (180), icon-192.png, icon-512.png, and icon-maskable-512.png, which keeps the mark inside the central 80% safe circle for Android adaptive icons.

6 Social

Link preview and GitHub card

Open Graph and Twitter cards are 1200 by 630; the GitHub social preview is 1280 by 640 (dark, same layout). Text is outlined. The tagline "Configuration for ZIO applications" and the zio.dev/zio-config address are placeholders until Milad confirms the wording.

7 Usage

Do not

Don't recolour the bars. Only the ink and accent pairs above.
Don't rotate, skew or flip the mark. The stair only reads as a Z one way.
ZIO Config
Don't set text in the accent on white. It is 3.53:1.
Don't add shadows, gradients or outlines.
